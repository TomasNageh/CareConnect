# CareConnect Server

Node.js mock API for the CareConnect frontend. Data is stored in memory and resets on restart.

## Run

```bash
npm install
npm run dev
```

Runs at **http://localhost:3001**.

From the project root: `npm run dev:server` or `npm run dev` (starts frontend + server).
